# Changes made

## Accessibility
- Added a skip link so keyboard users can jump directly to the main content.
- Kept a logical heading hierarchy and used semantic `header`, `nav`, `main`, `section`, `aside`, `figure`, and `footer` elements.
- Added a descriptive navigation label and corrected the broken in-page link to the Lists section.
- Improved text and link contrast and added a visible keyboard-focus indicator.
- Increased navigation link target size and added responsive layout rules for smaller screens.
- Preserved descriptive alternative text for the cat image and improved its wording.
- Improved table structure with a caption and clear row/column headers; made the table container keyboard-focusable for horizontal scrolling where needed.
- Added a reduced-motion preference rule.
## Web ethics and user experience
- Rewrote unclear text and corrected spelling/grammar to make the page easier to understand.
- Made the external link's new-tab behaviour clear and added `rel="noopener noreferrer"`.
- The page does not include analytics, tracking scripts, forms, or collection of personal information. No unnecessary personal data is requested.
- Used descriptive link labels rather than relying on vague wording.
