Headings and paragraphs

Headings and paragraphs are block-level elements. Headings create a logical outline that helps people understand the page.

Headings

HTML has six heading levels. Use them in a logical order. If you want to change a heading's appearance, use CSS rather than choosing a heading level only for its size.

Paragraphs

Paragraphs contain related body text. They should not contain other block-level elements.

Special characters

HTML supports named character references and numeric references. Examples include ®, quotation marks ("), an ampersand (&), and the less-than (<) and greater-than (>) symbols.
